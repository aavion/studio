# IconCaptcha integration (Feature Draft)

> **Status**: Draft  
> **Updated**: 2026-05-20   
> **Owner**: Core  
> **Purpose:** Placeholder draft for a concrete IconCaptcha integration after the generic captcha extension point is defined.

## Overview
- Defines the planned IconCaptcha implementation separately from the core captcha extension contract.
- Depends on security, setup, error handling, public form workflows, and plugin module extensibility.
- Keeps early security work focused on replaceable captcha provider contracts before a concrete captcha system is selected.

## Outline
IconCaptcha should be treated as one possible captcha provider, not as a hard-coded core dependency. The security draft defines the generic `CaptchaProvider` contract, resolver behavior, workflow configuration, rate limiting, validation feedback, and extension boundaries. This draft will later describe how IconCaptcha integrates with that contract once the preferred implementation variant has been reviewed.

The first implementation should avoid coupling public forms directly to IconCaptcha classes. Contact forms, login throttling, registration, anonymous submissions, or future public workflows should ask the captcha resolver for the configured provider and handle validation failures through the shared error handling and validation model.

## Technical Specifications
- Implement IconCaptcha behind the generic captcha provider contract once the concrete variant is approved.
- Keep provider selection configurable per workflow.
- Keep templates theme-compatible, but do not require themes to know provider internals.
- Use Symfony Validator constraints or form-level validation for user-facing captcha errors where practical.
- Use Symfony Rate Limiter alongside captcha checks; captcha should not be the only abuse-control layer.
- Log provider failures with safe context and without leaking challenge internals.
- Keep replacement open for module-provided captcha providers.

## Testing & Validation
- Test provider selection through the generic captcha resolver.
- Test successful and failed captcha validation paths.
- Test recoverable validation feedback on public forms.
- Test rate-limited captcha failure behavior where applicable.
- Test that disabling IconCaptcha or selecting another provider does not break workflows using the generic contract.
