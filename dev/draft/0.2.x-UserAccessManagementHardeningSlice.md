# User Access Management Hardening Slice

Status: implemented  
Created: 2026-05-28  
Owner: Codex

## Goal

Move the user-management foundation closer to feature completeness by closing token lifecycle, notification, and cleanup gaps without adding the real mailer yet.

## Checklist

- [x] Add configurable account-link TTL for invitation and registration links, defaulting to 24 hours.
- [x] Keep password-reset links on a fixed one-hour TTL.
- [x] Add an admin notification recipient setting for registration approval requests.
- [x] Make message-log delivery emit stable mail-flow keys for invitation, registration, password reset, approval request, approval, and rejection events.
- [x] Notify users through the delivery stub when pending registrations are approved or rejected.
- [x] Enforce token expiry at acceptance/reset time and show expiry in admin/user-facing token views.
- [x] Add a console cleanup command for expired account tokens that can later be wired into the global stale-cleanup scheduler.
- [x] Cover the lifecycle changes with targeted tests.
- [x] Update class map, worklog, draft notes, and translations.
